# Mario-Rabbids-Community-Versus-Sets

How to play the mod:

1. Download the "moria" folder

2. Put it inside a folder named "import"
  
3. Use this repacker: [https://github.com/gggga00/mrkb-romFS-repacker](https://github.com/gggga00/Mario-Rabbids-Reimportation-Tool) and your sdfdata files to reimport the folder into its sdfdata structure.

You will need your own extracted sdf.toc and the sdfdata files A-0016, A-0018.
  
4. Put the modified sdfdata files (keeping the same name as the original) into the romFs folder in a modded switch or emulator.

You cannot put it in raw, however: It must be within the same folders in the same order as the original. This would be romfs/moria/sdf/nx/data/. You will need to create each of these folders yourself. 

In an emulator, right click on Mario + Rabbids Kingdom Battle and select “Open Mod Location”. Put your folder here!
On your modded Switch’s SD card, you need to place it within atmosphere/contents/010067300059A000
In both cases, this would allow the modified sdfdata file to overwrite the original! 

5. To unlock the custom sets you will need to replace your RKB1_PVP_PVP.SAVE with the one from this repo.

How to contribute:

1. Download the file you want to modify from here (this is to ensure that compatibility with the rest of the mod). There is also a "Fork" button on this page that you can use to 'copy' the github page to your own account, where you can modify everything to your hearts content. 
2. Follow the [wiki](https://github.com/gggga00/Mario-Rabbids-Community-Versus-Sets/wiki) for directions on how to add/modify versus sets
3. Make a pull request with your modified files. Here is an explanation on how to make a pull requests: https://docs.github.com/en/pull-requests/how-tos/create-pull-requests/creating-a-pull-request
